# HabitTracker-SwiftUI

A simple habit-tracking iOS app built with **SwiftUI** and **MVVM**.

## Features

* Add and delete habits
* Mark habits as completed
* Track daily progress
* Choose habit categories and icons

## Tech Stack

* Swift
* SwiftUI
* MVVM Architecture

## Getting Started

Open `HabitTracker.xcodeproj` in Xcode and run the app.

Built as part of my journey toward becoming an iOS developer.
